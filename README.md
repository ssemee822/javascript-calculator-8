# 문자열 덧셈 계산기

우아한테크코스 자바스크립트 미션: **입력 문자열에서 숫자를 추출해 합을 계산**하는 콘솔 앱.  
기본 구분자(`,`, `:`)와 **커스텀 구분자(`//X\n`)**를 지원하며, **형식 오류 시 `[ERROR]`로 시작하는 메시지**를 출력한다.

---

## 요구사항 요약

- 입력이 빈 문자열 `""`이면 **0**을 반환한다.
- 기본 구분자: `,`(쉼표), `:`(콜론)  
  예) `1,2:3 → 6`
- 커스텀 구분자: 입력 시작이 `//X\n`이면 **X(정확히 1글자)** 를 추가 구분자로 사용  
  예) `//;\n1;2;3 → 6`
- **형식 오류**는 모두 에러로 처리하고, 출력은 반드시 **`[ERROR]` 접두어**로 시작해야 한다.
- **출력 형식은 정확히** `결과 : <합>` (공백/콜론 위치 포함)

---

- **Node.js ≥ 22.19.0**

## 사용 방법

| 입력         | 설명                   | 결과 |
| ------------ | ---------------------- | ---- |
| `""`         | 빈 문자열              | `0`  |
| `1,2:3`      | 기본 구분자 `,` `:`    | `6`  |
| `//;\n1;2;3` | 커스텀 구분자 `;` 사용 | `6`  |

---

## 에러 규칙

다음 상황은 **에러**이며, 출력은 **반드시 `[ERROR]`로 시작**해야 한다.

- **빈 토큰**: 예) `1,,2`, `//;\n1;`
- **숫자 아님**: 예) `a,1`, `1:2:x`
- **음수**: 예) `-1,2`
- **헤더 형식 오류**: `//X\n`가 아니거나, `X`가 1글자가 아님, `\n` 누락
- **정수 안전 범위 초과**(필요 시)

예시 출력:

```
[ERROR] 비어 있는 값이 포함되었습니다.
[ERROR] 숫자만 입력할 수 있습니다.
[ERROR] 음수는 허용되지 않습니다.
[ERROR] 커스텀 구분자 형식이 올바르지 않습니다. (\n 누락)
```

## 구현 메모(요약)

- `App.run()`
  - 안내 문구 출력 → `Console.readLineAsync()`로 한 줄 입력
  - 파싱/검증 후 합산 → `Console.print("결과 : " + sum)`
  - 예외 발생 시 메시지에 **`[ERROR]` 접두어 보장** 후 출력
- 파싱 로직
  - `//X\n` 헤더 존재 시 `X`를 **추가 구분자**로 등록(한 글자만 허용)
  - 기본 구분자 `,`와 `:`는 항상 활성
  - 정규식 특수문자 구분자에 대비해 **이스케이프** 처리
- 검증 로직
  - 토큰은 **0 이상의 정수 문자열**만 허용(`^\d+$`)
  - 빈 토큰/음수/숫자 아님/헤더 형식 오류 시 예외

## 개발 흐름

1. **feat(app):** 빈 입력=0, 기본 구분자 합산
2. **feat(parser):** 커스텀 구분자 `//X\n` 파싱 + 기본 구분자와 동시 분리(정규식 이스케이프)
3. **feat(validate):** 빈 토큰/비숫자/음수/형식 오류 검증 + `[ERROR]` 표준화

> 테스트는 단계마다 `npm run test`로 확인하세요.
